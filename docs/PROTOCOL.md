# 通信协议（真值表）

> 本文件于 2026-11-19 由**代码实际行为**重建，不再是手写推测。
> 生成依据：`MainActivity.sendCmd/sendRaw`、`BoardView.onTouchEvent`（发出侧）、
> `PcReceiver.handle/handleButton`（接收侧）。
> 改动任何一端都必须同步改本表。

## 传输层

| 项 | 值 |
|---|---|
| 载体 | UDP（另有蓝牙 SPP 备用通道，当前版本未启用） |
| 端口 | 默认 `51234` |
| 编码 | UTF-8 文本 |
| 分帧 | 一行一条，`\n` 分隔 |
| 服务器 | 无，纯局域网点对点 |

## 手机 → 电脑

| 指令 | 参数 | 说明 |
|---|---|---|
| `ping [token]` | 可选 token | 广播发现 / 心跳 |
| `hello <base64>` | 机型名 UTF-8 的 base64 | 上报设备名，电脑显示 |
| `mv <dx> <dy>` | 整数像素，可带负号 | 光标相对位移 |
| `btn <id> down` | id + `down`/`up` | 按键按下 |
| `btn <id> up` | | 按键抬起 |
| `txt <base64>` | 文本 UTF-8 的 base64 | 文字输入 |
| `whl <n>` | 整数 | 滚轮，**正数向下**、负数向上 |

## 电脑 → 手机

| 指令 | 说明 |
|---|---|
| `pong [token]` | 回应 `ping`，token 原样带回 |

| id | 功能 | 电脑端实现 |
|---|---|---|
| 1 | 左键 | 单击 BUTTON1 |
| 2 | 右键 | 单击 BUTTON3 |
| 3 | 拖拽 | 切换按住/松开 BUTTON1 |
| 7 | Esc | 组合键 `ESC` |
| 8 | 复制 | 组合键 `CTRL+C` |
| 9 | 方向上 | 组合键 `UP` |
| 10 | 方向下 | 组合键 `DOWN` |
| 11 | 方向左 | 组合键 `LEFT` |
| 12 | 方向右 | 组合键 `RIGHT` |
| 13 | 确定 | 组合键 `ENTER` |
| 17 | 音量 + | `VolumeSet.exe up 4` |
| 18 | 音量 − | `VolumeSet.exe down 4` |
| 19 | 上一曲 | `MediaKey.exe prev`（400ms 防抖） |
| 20 | 下一曲 | `MediaKey.exe next`（400ms 防抖） |

| 26 | 中键 | 单击 BUTTON2（v2.3 新增） |

## 不联网的本地 id（只存在于手机端）

这些 id 由 `BoardView` 产生、`MainActivity.onBoardKey` 就地消费，**一个字节都不发出去**：

| id | 元素 | 本地行为 |
|---|---|---|
| 16 | 定中 | 置 `clutch`，按住期间丢弃陀螺仪数据 |
| 100 | 开/关 | 切换空中鼠标，读写 prefs |
| 101 | 状态条 | 无动作 |
| 102 | 设置 | 打开 SettingsActivity |
| 103 | 切换 | 圆盘方向/媒体模式 |
| 104 | 圆盘 | 容器 id，实际命中的是 9–13 / 17–20 / 25 |
| 105 | 滚轮条 | 容器 id，实际产生 204 / 205 |
| 200 | 主题 | 切换深/浅色并重建界面（v2.3 新增，不联网） |
| 204 / 205 | 滚轮步进 | 转成 `whl -1` / `whl 1` 发出去 |

> ⚠ `106`（收起/展开）在 `MainActivity.onBoardKey` 里有分支，但 `BoardView.buildElements()`
> 里**没有对应元素**，属于不可达代码。v2.0 要么补上元素、要么删掉分支。

## 旧版兼容指令（电脑端仍接受，手机端已不再发送）

| 指令 | 说明 |
|---|---|
| `clk L\|R\|M` | 单击，等价于 `btn 1/2/3` 的一次 down+up |
| `down L\|R\|M` | 按下不抬（拖拽的早期写法） |
| `up L\|R\|M` | 抬起 |
| `key <A+B>` | 直接发组合键名，如 `key CTRL+V`。电脑端测试方块与自定义键复用这条 |
| `btn 4` | 滚轮上（旧编号） |
| `btn 5` | 滚轮下（旧编号） |
| `btn 6` | 回车（旧编号，与 13 等价） |
| `btn 14` | 音量+（旧编号，与 17 等价） |
| `btn 15` | 音量−（旧编号，与 18 等价） |

保留理由：旧版 APK 仍可能连上来；且 `key` 指令是自定义键与自检板共用的实现路径。
代价只有几行 `switch`，故不删。

## 已知空缺

| 项 | 现状 |
|---|---|
| `btn 16` | 电脑端**没有**处理分支，收到会记一条「未配置的按键：16」。当前手机端不发，属安全冗余 |
| `btn 26+` | 未定义，落到同一条「未配置」日志 |
| 鉴权 | 无。同一局域网内任何设备都能发指令（设计如此，本项目定位是自用/朋友测试） |
