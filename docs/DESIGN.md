# 设计系统（v2.x）

> 这份文件是**唯一的视觉真值**。改外观先改这里，再改代码。
> 两份实现各有一个 token 文件，内容必须与此处一致：
> 手机端 `android/app/src/main/java/com/mzl/phonemouse/Theme.java`，
> 电脑端 `pc/src/phonemouse/ui/Ui.java`。

## 方向：仪器面板

把界面当一台**硬件**来画：连续机身、实体键帽、刻字标签、一颗状态灯。
语汇来自遥控器、混音台、相机手柄，而不是来自"管理系统模板"。

**为什么是深色**：这个软件的真实场景是关灯的卧室、昏暗的客厅，屏幕亮度往往调到最低。
亮底界面在这个场景里就是手电筒。深色不是为了酷，是场景决定的。
浅色作为备选保留（白天、投屏），token 一一对应。

## 颜色

| 角色 | 深色（默认） | 浅色 | 用在哪 |
|---|---|---|---|
| 机身 `BG` | `#171A1F` | `#ECECE7` | 整屏底色 |
| 状态区 `RAIL` | `#14171B` | `#E4E4DE` | 顶部一条，比机身再暗一档 |
| 键面 `KEY` | `#262B33` | `#FFFFFF` | 所有键 |
| 键缘 `KEY_LIP` | `#1A1E24` | `#D9D9D2` | 键的底缘（厚度感） |
| 按下 `KEY_DOWN` | `#323841` | `#F0F0EB` | 按下时的键面 |
| 主字 `INK` | `#EDEFF3` | `#16181B` | 标签 |
| 次字 `INK_DIM` | `#98A0AE` | `#5F6672` | 说明、未激活 |
| **强调 `LIVE`** | `#FFB324` | `#B46A00` | 通着 / 刚按下 |
| 压在强调上 `ON_LIVE` | `#171A1F` | `#FFFFFF` | 强调色上的字 |
| 结构线 `LINE` | `#39404B` | `#D3D3CB` | 1px 边 |
| 轨道 `TRACK` | `#1F232A` | `#E4E4DE` | 滚轮槽 |

**只有一个强调色**，它只表示两件事：链路通着、按键刚被按下。不做装饰、不做渐变。

## 层次

层次只声明一次：**一个底缘 + 一条顶高光 + 一圈结构线**。

- 键帽 = 底色圆/圆角矩形在 `cy`，同一形状在 `cy + 4~5px` 用 `KEY_LIP` 垫底 → 厚度
- 顶部一道 8% 白弧 → 受光
- 一圈 1px `LINE` → 边界
- 按下：底缘收到 1px、键面换 `KEY_DOWN`、边缘点亮 `LIVE`

**不再有**：6 层半透明投影、径向光斑、蓝紫渐变背景、白色胶囊卡片、1.5px 亮边。
这些是 v1.6 里"模板感"最重的东西，也是每帧几百次额外绘制的来源。

## 文字

- 标签：系统 `sans-serif-medium`，不用第三方字体（不加体积、不背许可）
- 读数（IP、计数、日志）：逻辑等宽 `Font.MONOSPACED` / `monospace`。
  注意不能用 `Consolas` —— 它没有中文字形，会显示成方块。
- 中文标签不加字距、不做全大写、不加眉标（kicker）

## 布局

**坐标一个数字都没改**（`docs/LAYOUT.md`）。那套位置是握持时拇指够得着的实测结果，
换皮不该动它。改的只有：顶部渐变横幅 → 平的状态轨、白卡片 → 键帽、投影 → 底缘。

## 两端一致

| | 手机端 | 电脑端 |
|---|---|---|
| 机身 | 整屏 `BG` | 窗口 `BG` |
| 状态 | 顶部状态区 + 灯 + 设备名 | 顶部状态轨 + 灯 + 设备名 |
| 按键 | 键帽矩阵 | 自检板 5×3 键帽 |
| 强调 | 开关键环、按下、已连接 | 点亮键、已连接、主按钮 |

## 交互与状态

- 震动：按下 15ms，短、克制，只确认"摸到了"
- 按下反馈：位移 + 变亮 + 强调色边，三件事同时发生，200ms 内结束
- 键盘焦点、对比度：标签 ≥4.5:1，大字 ≥3:1

## 不做的事

- 不用 emoji 当图标（原来的 🎤 已删：它只是打开键盘，并没做语音）
- 不叠嵌套卡片、不给卡片加宽大软阴影
- 不用渐变文字、玻璃拟态、单侧色条
