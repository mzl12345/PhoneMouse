# 使用说明

## 一、电脑端

1. 双击 `pc\启动接收端.bat`
2. 窗口标题出现「手机空中鼠标 · 已连接」即可
3. 首次运行 Windows 可能提示防火墙，需允许 UDP 51234

## 二、手机端

1. 安装 `app-debug.apk`
2. 打开 App，顶部「开」变成绿色 = 已连接
3. 「开」就是空中鼠标总开关（关掉后手机不再控制电脑）

## 三、空中鼠标怎么用

- 手腕**向右转** → 光标向右；**向左转** → 向左
- **抬头** → 向上；**低头** → 向下
- 停下来光标就停，不需要一直保持角度

### 定中（重要）

一直往一个方向转，手会越转越歪。这时：

1. **按住「定中」**
2. 把手机转回舒服的姿势（屏幕里光标不动）
3. 松开，从新姿势继续控制

等于「抬起鼠标放回桌子中间」。

## 四、按键

| 按键 | 作用 |
|---|---|
| 左 / 右（两个半圆） | 鼠标左键 / 右键 |
| 拖拽 | 按住左键不放，再点一次松开 |
| 复制 | Ctrl+C |
| 回车 | Enter |
| Esc | Esc |
| 定中 | 重新对中（见上） |
| 自定1~4 | 自定义键，电脑端会记录，功能待配置 |
| 圆盘 | 上下左右 + 确定（Enter） |
| 切换 | 圆盘变媒体模式：上=音量+，下=音量−，左=上一曲，右=下一曲 |
| 滚轮条 | 上下滑 = 鼠标滚轮 |

## 五、打字

1. 点底部输入条 → 进入**全屏输入**（按键自动隐藏）
2. 输入完点「发送」，文字会直接输入到电脑当前光标处（中文安全，不受输入法干扰）
3. 点「取消」返回按键界面

## 六、调手感

设置 → 鼠标手感：

- **灵敏度**：转同样角度光标走多远（默认 45）
- **平滑**：越大越稳但越慢（默认 45）
- **反转方向**：仅当你觉得方向反了才开

## 七、常见问题

| 现象 | 处理 |
|---|---|
| 显示「未连接」 | 确认电脑端已启动、手机和电脑在同一 Wi-Fi |
| 光标自己走 | 放桌上静止 20 秒应完全不动；若漂，设置里点「重新校准」 |
| 按键没反应 | 看电脑端日志里有没有「未配置的按键 xx」 |
| 输入法吃掉数字/字符 | 已用 Unicode 注入，不会发生；若仍有，检查是否点了键盘 |
