# 架构说明

## 组成

```
手机 App ──UDP(局域网)──> 电脑接收端 ──Robot/SendInput──> 系统鼠标键盘
```

- **手机端**：采集陀螺仪 → 算光标位移；按钮发送按键编号
- **电脑端**：UDP 监听 → 解析指令 → 注入鼠标键盘事件

## 手机端主要类

| 文件 | 职责 |
|---|---|
| `MainActivity` | 主界面、传感器融合、发现电脑、发送指令 |
| `SettingsActivity` | 参数设置（灵敏度/平滑/反转/连接/布局） |
| `CalibrationActivity` | 拇指可及区域校准 |
| `ThumbPadView` | 弧形按键控件（拇指扇区） |
| `DPadView` | 圆盘（上下左右+确定+音量） |
| `ScrollBarView` | 右侧滚动条（速度驱动） |

## 传感器算法

- 用 **陀螺仪** 读角速度，积分成角度增量（转多少走多少，停手即停）
- 用 **重力传感器** 判断握持姿态，决定横向取哪个轴（竖握取 Z、平放取 Y）
- 零偏：静止时累积 25 帧取平均；死区 1.5°/s 以下视为静止
- 平滑：一阶低通，系数来自设置里的“平滑”滑条

## 电脑端

- 单个 Java 类 `PcReceiver`：Swing 界面 + UDP + Robot
- 文字输入用 `TypeText.exe`（SendInput Unicode，绕开输入法候选词）
- 界面：左上状态、设备名、2×5 测试方块、使用说明、开发者日志（默认隐藏）
