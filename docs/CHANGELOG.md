# 变更记录

## v1.0（2026-11-18）

### 手机端
- 陀螺仪空中鼠标：转多少走多少，停手即停
- 零偏补偿 + 死区 + 可调平滑
- 自动发现电脑（UDP 广播），无需手填 IP
- 拇指可及区校准（画布扫一遍），弧形按键自适应
- 弧形按键：左键/右键/拖拽/回车/Esc/复制（圆形，按下变蓝+震动）
- 圆盘：上下左右 + 确定 + 音量±
- 右侧滚动条：拖动速度决定滚动速度，松手回中
- 收起/展开弧形按键
- 设置页：空中鼠标开关、灵敏度、平滑、反转、布局、连接、关于
- 标题旁圆形开关一键开关空中鼠标

### 电脑端
- 接收端：状态圆点、设备名、2×5 按键测试方块
- 按键编号映射（btn 1-15）
- 拖拽：按一下开始、再按一下结束
- 中文输入：SendInput Unicode，不撞输入法候选词
- 开发者日志默认隐藏

### 已知问题
- 纯蓝牙 SPP 未完成（见 `_backup\v2-bluetooth-spp`）
- 手机与电脑需同一局域网
## v1.4（2026-11-18）界面与图标

- 全新排版，按 PPT 设计稿坐标 1:1 还原（BoardView 整屏绘制）
- 所有按键改为「浮起」质感：多层投影 + 高光面层
- 背景改为蓝→紫→粉多段渐变 + 5 个彩色光斑
- 圆盘改为四层堆叠 + 投影，中心「确定」同样浮起
- 顶部：开 / 名称状态胶囊 / 设置，等高一排
- 圆盘「切换」支持方向 ↔ 媒体两种模式（媒体：音量±、上一曲/下一曲）
- 左/右改为两个半圆，中间留缝
- 新增 4 个自定义键（21-24），电脑端按键表扩到 3×5
- 全屏输入（学微信）：点输入框后隐藏所有按键，只留大文字框
- 输入条自动贴住键盘上沿，不再被挡
- 修复：松手后按键仍高亮（splitSide 未复位）
- 修复：媒体键在电脑端无响应（17-20 未映射）
- 修复：自定4 与方向右键编号冲突（12 → 24）
- 新增应用图标（自适应图标 + 5 档密度）
